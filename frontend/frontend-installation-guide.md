# Frontend Installation Guide

---

## 🇺🇸 EN

## 📦 Installation Guide — Frontend

### Prerequisites

- Install Node.js v18.1:
```bash
sudo apt install nodejs
```

- Install Yarn:
```bash
npm install --global yarn
```

- Install Lerna:
```bash
yarn global add lerna@6.6.2
```

---

### 📥 Clone Repository

```bash
git clone -b dev https://github.com/democracyonchain/asuncion-frontend.git
```

---

### 📦 Install Dependencies

Navigate to the project folder:

```bash
cd asuncion-frontend
npm install
```

---

### 🚀 Run Application

```bash
yarn start:local
```

---

### 🌐 Access

Open in browser:

```
http://localhost:9000/
```
